# What is in this repository, and what is deliberately not

Not legal advice. This is a description of what was actually done and why,
written so that anyone can check it rather than take it on trust.

## The rule

**The numbers travel. The game does not.**

Everything here is either a measurement, or something this project wrote. There
is no game code, no artwork, no audio, no ROM, no patch, and no link to any of
those. That is not a promise to be taken on faith — it is enforced by
`tools/validate.py`, which runs on every pull request, and it is a *whitelist*:
any string in any data file that does not match a pattern this project
generates fails the build.

`tools/prove_validator.py` injects eight kinds of leak — a source symbol, an
artwork name, a lane label, a borrowed sentence, and four structural faults —
and demonstrates that each is rejected. A check that has only ever passed is
not a check.

## Never in this repository

| | why |
|---|---|
| game source, in any form or any language | not ours |
| artwork, sprites, sprite rips, screenshots | not ours |
| audio, in any form | not ours |
| ROMs, ROM fragments, patches, diffs against a ROM | not ours |
| names of routines, labels, files or artwork from the game | short and functional, but still lifted, and the whitelist blocks them |
| links to anywhere hosting any of the above | pointing at it is its own problem |

## What the data actually is

Rectangles and integers.

A strike record is a box and two damage bytes. A pose is a list of rectangles
describing where the pieces of a sprite sit relative to its anchor — the
*extents*, not the pixels. Frame data is counts of ticks. None of it can be
used to reconstruct any part of the game, and all of it is the kind of factual
description a strategy guide has always contained.

Identifiers are generated by this project (`liu-kang/hikick`), not taken from
anywhere. Where the game's own tables share one record between characters, that
is recorded as a membership list rather than by repeating a name.

## Character and game names

Character names are used to identify the characters they name, because a
hitbox viewer that called them Fighter 1 through Fighter 17 would be useless.
That is the ordinary nominative use every fighting-game wiki, tier list,
tournament stream and strategy guide makes.

No logos, marks, box art, or stylised wordmarks are used anywhere in this
repository, and the project is named for itself rather than for the game.

The data files are published as factual documentation. This project claims no
rights in the underlying game, and asserting a licence over measurements of
someone else's work would be its own kind of overreach. Use them; attribution
is appreciated and not demanded.

## If you think something here crosses a line

Open an issue, or contact the maintainers, and say which file and which line.
Anything genuinely over the line comes out — that is a cheaper conversation for
everyone than the alternative, and this project would rather be corrected than
be right.
